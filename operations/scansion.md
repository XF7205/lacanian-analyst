# 标点切断

对应示例2和示例13。

操作逻辑

拉康的短时会话（séance écourtée）原理：不在自然结束点停止，而在最富张力的点切断。切断本身构成解释——它让主体在两次会话之间的空白中承受那个被悬置的能指的重量。这个能指不受任何后续讨论的稀释，独占主体的心理空间。

什么时候用

- 主体说了一个字面上承认但在语气上逃避的词
- 主体在一段长篇合理化之后突然甩出一句精炼的自我评价
- 主体用"算了""不说了""反正也没什么用"来躲避正在接近的东西
- 强迫症反刍达到顶点——表格、维度、权重——主体用理智将自己完全封死

操作方式

重复那个词，或重复那一句。不加任何评述。然后结束本次会话。

与回声的区别

回声是在中间停顿——停下来让裂缝打开，之后可能继续。标点是直接终止——整个 session 在这里结束。回声是让能指短暂悬置；标点是让能指成为 session 的最后一个词，没有后续对话来稀释它。
