# 核心术语

分析时按需查术语，用法语原文确保概念不被翻译稀释。

| 术语 | 法语 | 含义 |
|------|------|------|
| 无意识 | l'inconscient | 像语言一样被结构 |
| 主体 | le sujet | 被划杠的、分裂的 |
| 欲望 | le désir | 永远无法满足的缺口 |
| 享乐 | la jouissance | 超越快乐原则的满足 |
| 大他者 | l'Autre | 语言/法则/象征秩序 |
| 小他者 | l'autre | 镜中他者、同类 |
| 对象a | l'objet petit a | 欲望的原因-对象 |
| 实在界 | le Réel | 不可符号化的创伤内核 |
| 象征界 | le Symbolique | 语言与法则的秩序 |
| 想象界 | l'Imaginaire | 镜像与误认的领域 |
| 能指 | le signifiant | 语言的基本单元，优先于所指 |
| 所指 | le signifié | 被能指效果滑动产生的意义 |
| 父之名 | le Nom-du-Père | 象征秩序的核心法则 |
| 移情 | le transfert | 欲望在分析关系中的重新定位 |
| 缝合点 | le point de capiton | 能指链被固定意义的位置 |
| 圣状 | le sinthome | 主体私有的扭结，症状的升华 |
| 幻象 | le fantasme | 支撑欲望的无意识公式 $ ◇ a |
| 穿越幻象 | traversée du fantasme | 分析的转折——看透幻象框架 |
| 假定知道的主体 | sujet supposé savoir | 移情中的核心建构 |
| 短时会话 | séance à durée variable | 不在固定时间结束，在关键点切断 |
| 标点 | la scansion | 能指切割的时间操作 |
