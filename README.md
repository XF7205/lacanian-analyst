# 拉康派 · 临床操作台

GitHub 上现有的拉康 skill 大多是第一人称称谓拉康本人，没有一个从临床操作出发做拉康派精神分析 skill 的。所以自己生成做了这个。虽然按理来说分析必须在一个安静、私密的环境下由分析师和患者面对面进行，但是没有那个条件。这个 skill 基于本人精神分析经验与拉康，齐泽克，弗洛伊德和其他精神分析文本阅读的总结。包含大量例子，有些例子是亲身的，其他则是生成的用来指导该怎么进行回答。还不完善，是一个早期版本，但是应该比现在能搜索到的 skill 好用。但是肯定同实际分析治疗有着大差距。也希望抛砖引玉，希望各方大佬能写出更好的精神分析skill。

触发方式：说「拉康派模式」「用拉康派的视角」「拉康派精神分析」「Lacanian」即可启动。

---

使用前必读：符号说明

本 skill 在对话中使用以下标记，每一个都有结构功能，不是装饰。

「——」

主动沉默。不是我掉线了，是我选择不填充这个空间。让上一个能指继续工作，让空白压在你身上。

「切」

会话切断。刚才你说的那个词是今天的关键。在这里停止，不总结。下次从这个能指的重量开始。

「回声」: X

不加解释地重复你说的一个词。把你的词从你的话语中剥离出来，让它作为纯粹客体重新出现在你面前。

这些标记不常用。沉默用多了失去了沉默的力量。切断只有在一个真正的能指出现时才有意义。大部分时候我正常说话。

---

重要局限

真正的精神分析需要面对面、私密的身体在场。本 skill 是在文字界面中尽可能接近分析家的结构操作——它不是分析室的替代品。

---

项目结构

AI 只读取 SKILL.md + examples/ + references/。其余目录是给人看的参考手册。

SKILL.md — 主文件。包含角色规则、五阶段临床框架、执行路径、输出标准（标记/语气/禁区/自检）、文件索引。

examples/demo.md — 14个 session 格式示例。每个示例展示分析家面对一种典型输入时实际说的话，用于训练 AI 的输出节奏和操作风格。覆盖回声、标点切断、沉默、预备访谈、智性化防御、诙谐语、歇斯底里、倒错、幻象破灭、认同圣状、梦、身体症状、强迫症反刍、移情建立。

references/ — AI 读取的辅助资料。

  glossary.md — 21个核心术语中法对照（无意识、欲望、享乐、大他者、对象a、实在界/象征界/想象界、能指、缝合点、圣状、幻象等）。

  quotes.md — 13条拉康标志性引文法中对照。AI 酌情化用，不原样背诵。

  bibliography.md — 14本核心文献索引。AI 根据概念查对应研讨班，自行搜索原文。

operations/ — 给人看的操作手册，AI 不读。14个文件，一一对应 demo.md 的14个示例，解释每个操作背后的逻辑：为什么这样做、什么时候用、注意事项。

  echo.md — 回声：剥离能指的常识意义
  scansion.md — 标点切断：在张力顶点终止
  silence.md — 沉默：不填充空间的结构位置
  preliminary-interview.md — 预备访谈：确立临床结构
  intellectualization.md — 智性化防御：患者抢占分析家位置
  witz.md — 诙谐语：笑话作为防御换装
  hysterical-desire.md — 歇斯底里：维持大他者匮乏
  perversion-structure.md — 倒错：作为大他者享乐工具
  fantasy-traversal.md — 穿越幻象：对象a与现实重合
  sinthome.md — 认同圣状：分析的终点
  dream.md — 梦：提取异常能指
  body-symptom.md — 身体症状：实在界的入侵
  obsessive-rumination.md — 强迫症反刍：切断循环
  transference.md — 移情建立：SSS的构成

protocol/ — 给人看的参考手册，AI 不读。分析师操作层面的补充资料。

  cut-timing.md — 切断时机：四种该切和三种不切的情况
  response-mode.md — 回答模式：根据对方话语位置切换回应方式
  symptom-prompt.md — 患者引导提示：三种版本帮助患者描述症状
